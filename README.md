## Learning Resources for each branch

Currently I am learning about AI and Data Science throug different resources:

- **Local Branch**: Contains files that I expect to run locally or related to topics that I found somewhere and wanted to explore.

- [**Essential Math for Data Science by Thoma Nield (EMDS)**](https://www.oreilly.com/library/view/essential-math-for/9781098102920/): The early release of the 2022 5th edition. A book that I'm using to learn the basics behind the big concepts, also to understand better the statistical aspects of DS, since is the weakest area in my background.

- [**Hands-on Machine Learning with Scikit-Learn, Keras, and TensorFlow by Aurélien Géron (HMLSKT)**](https://www.oreilly.com/library/view/hands-on-machine-learning/9781492032632/): The 2019 2nd edition, is basically a bible for the ML community. Was the first book I started to read.

- [**Google Developer TensorFlow Pathway (GDTP)**](https://developers.google.com/learn/pathways/tensorflow): Is a short course on how to use TensorFlow to build Convolutional Neural Networks, but the simple explanations and the code examples are very illustratives.
